# Door Escape Frenzy

make a 3d game similar to Roblox doors. make the rooms look like this and make it so if the player gets close enough to the door it opens with an animation instead of having to do an input. add a timer system with the time ticking down by seconds every door. levers spawn about every 70 doors. click the levers to add more time. make the rooms be based off of the images. add no entities
